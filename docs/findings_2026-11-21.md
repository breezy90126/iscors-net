## A. 相對於論文的新發現

### 方法層面（論文沒做、或做法不同）
1. **有限錄影長度（finite‑T）偏差是 D4 趨勢的主因**：樣本平均扣除讓慢 pixel 的尾巴被壓低，偏差隨 γ 變。
   用 exact expected estimator 做正向擬合後，全段 T 與半段 T/2 一致（D4b span 通過）。
   → 論文直接擬合 ACF 的 D* map 對慢區有系統性偏差。
2. **白噪聲佔 10–18%**：需要 nugget 項；不放會把噪聲誤當成極快族群。
3. **ACF 形狀指數 α ≈ 0.5（修正後）**：是 iPSF 多 q 平均 + 像素內異質性的有效指數，
   不能直接當 MSD 指數，也不能直接對應論文 slope=3 的聚合物論述。
4. **三種雜訊篩法（G / G+CV² / τ+CV² GEVD）得到相同 P(D)**：結果對篩選方法不敏感。

### 物理層面
5. **核內是兩群動態，不是單一 D\***：快群 ≈ 4–5 µm²/s、慢群 ≈ 0.26 µm²/s（比值約 20×）。
   論文的 D* map 是兩群的加權平均。
6. **慢群是真的，不是漂移假影**：matched high‑pass（W=1501）後慢群質量保留 0.73×，與無漂移模擬一致；
   原本漂移把慢群位置拉低，去漂移後才是 ≈ 0.26。
7. **核仁比核質快**（γ 約 2.7×）。
8. **快/慢比例在空間上幾乎均勻（≈ 0.4）**：Wiener 比例圖半段相關 r = 0.19、tile 圖 r = 0.41。
   快帶與慢帶 RMS 圖是同一圖案（核仁暗、大尺度起伏一致），快帶只是估計噪聲較小、看起來平滑。
   → 空間上變的是「擾動量」（密度/對比，類似 CV²），不是「怎麼動」。
   → 論文 D* map 的空間變化，可能主要反映擾動強度與加權，而非局部動態種類改變（待 TODO 5 驗證）。
9. **影片：慢帶是 PSF 尺寸（2–3 px）speckle 原地去相關**，沒有成團、可追蹤的移動結構，
   符合「次解析度散射體疊加」的 iPSF‑kernel 前提。
10. **ICA 'other'（sign −1）抓到核仁；半橢圓可能是 perinucleolar 殼**（condensate 分量中的環）。

### 目前的解讀（假說）
- 慢群強度圖與染色質密度相似；快群圖其實也相似（同圖案）。
- 較支持「同一染色質的快/慢模態」或「流動池均勻混在染色質中」，而非互補的 interchromatin 流動池。
- 單一條件下無法再往下分辨，需要藥物擾動（見 B‑2）。

## C. 階段性結論（CONTIN 分析）

**CONTIN 適合做「群體層級的 D 分布」，不適合做「每個 pixel 的 D map」。**

能可靠回答：
1. 核內 D 為雙峰：快群 ≈ 4–5 µm²/s、慢群 ≈ 0.26 µm²/s（約 20×）。三種雜訊篩法一致、去漂移後仍在、ROI/tile 一致。
2. 單一 D* 擬合會混合兩群，且受 finite‑T 與白噪聲偏差；把 finite‑T、nugget、iPSF 放進正向 kernel 後才得到無偏分布。
3. 可比較比例：核仁 vs 核質、不同條件之間。

做不到 / 還不能說：
1. 空間解析的 P(D)：每 pixel 資訊不足；快慢比例幾乎均勻，可重現的空間變化只有擾動強度。
2. 絕對 D：需實測 iPSF（目前可能整體差一個倍數）。
3. 分子身分：label‑free 只知道有兩種動態狀態，需藥物擾動或螢光對照。

一句話：CONTIN 證明核內同時存在兩種相差約 20 倍、到處等比例混合的動態群體；
下一步的價值在於比較不同條件下兩群的 D 與比例如何改變，而非更細的空間圖。
