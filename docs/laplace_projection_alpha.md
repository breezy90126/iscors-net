# 拉普拉斯投影能不能像 DLS 一樣分出不同的 α？

**結論：不能——而且不是「工程沒做好」，是這個量測本身的結構決定的。**

在 per-pixel 層級，α 跟「速率分佈的寬度」是**同一個自由度**，不是兩件可以互相分開的事。
拉普拉斯反演只是把 `G(τ) = A/(1+γτ^α)` 的 (γ, α) 換一組座標寫出來，不會生出新資訊。
唯一還有意義的用法是 **ROI 平均後的 bulk 診斷**（見最後一節）。

所有數字都可以用 `python3 scripts/laplace_identifiability.py` 重跑（純標準庫，無相依）。
工具在 `utils/laplace_spectrum.py`。

---

## 一、先講最關鍵的：DLS 的 kernel 跟這裡不一樣

CONTIN 在 DLS 能work，前提是**單一 q**：

```
DLS:    g1(τ) = ∫ P(Γ) e^(−Γτ) dΓ ,  Γ = D q²      每個粒徑 = 一條純指數
```

每個粒徑對應一條乾淨的指數，反演才有「把兩群分開」的意義。

iSCAT/iSCORS 的 per-pixel ACF **不是這樣**。一個 pixel 收的是 PSF 涵蓋的**整段 q** 積分過的訊號——
這正是為什麼模型是 `A/(1+γτ^α)` 這種 FCS 型代數式，而不是指數和。而且：

> **α = 1 的 `1/(1+γτ)`，恰好就是 `p(Γ) = (1/γ)e^(−Γ/γ)` 的拉普拉斯轉換。**

也就是說，**單一、完全均勻的成分，在拉普拉斯空間裡本來就長成一條橫跨所有 decade 的寬分佈**。
它的 log₁₀ 寬度是解析值 `π/(√6·ln10) = 0.557 decade`（`utils/laplace_spectrum.py` 的 self-test 會跑出 0.54，符合）。

所以在 iSCAT 裡，「譜很寬」**不等於**「多分散」——寬度主要是成像光學的 q 積分造成的。
拿 DLS 的指數 kernel 去反演 q 積分過的資料，本身就是 kernel mismatch：
你反出來的東西是「粒徑分佈」和「光學 q 權重」糾纏在一起，原則上分不開。

## 二、α 就是譜寬（EXP 3）

對每個 α 反演出正的速率譜，看它長什麼樣：

| α | 反演殘差 | 譜寬 (decade) | 峰數 |
|---|---|---|---|
| 0.6 | 0.0020 | 0.88 | 1 |
| 0.8 | 0.0006 | 0.70 | 1 |
| 1.0 | 0.0003 | 0.54 | 1 |
| 1.2 | 0.0010 | 0.43 | 1 |
| 1.5 | 0.0033 | 0.31 | 1 |

**全部單峰**，寬度隨 α 單調變化。fitter 容許的整段 α ∈ (0,2) 都能用一個正的速率譜表示，
殘差遠低於雜訊 → 拉普拉斯反演對 α **完全沒有鑑別力**，它只是把 α 換算成寬度。

「分出不同的 α」在這裡是個 category error：反演給你的是 Γ 的分佈，
而 α ↔ 分佈寬度是一對一的。沒有「兩群、各自有自己的 α」這種可解的東西。

## 三、兩個方向的簡併都成立（EXP 4、EXP 5）

**正向**：真的有兩群（速率比 R），用單一 (γ, α) 去 fit——

| R | 單成分殘差 | per-pixel 測得到？ | 最佳單成分 fit |
|---|---|---|---|
| 2 | 0.0011 | 否 | γ=0.155, **α=0.98** |
| 5 | 0.0031 | 否 | γ=0.190, **α=0.88** |
| 10 | 0.0061 | 否 | γ=0.227, **α=0.79** |
| 30 | 0.0122 | 否 | γ=0.316, **α=0.61** |
| 100 | 0.0180 | 否 | γ=0.448, **α=0.44** |

即使速率差 **100 倍**，殘差 0.018 還是低於 per-pixel 雜訊 0.041 → 測不到。
而且看最後一欄：**混合不會消失，它變成一個較低的 α**。α 本來就已經在扛多分散度了。

**反向**：α=0.6 的異常擴散曲線，用兩條 α=1 指數去 fit
→ 殘差 0.0115 ≪ 雜訊 0.041 → **INDISTINGUISHABLE**。

兩個方向都簡併，代表這不是選錯方法，是資訊本身不夠。

## 四、資訊上限：kernel 條件數 + 實測雜訊

**Laplace kernel 的奇異值**（τ = 1..128，2.11 decade）：

```
1.00  0.289  0.108  0.0437  0.0188  0.0075  0.0030  0.0012  0.00037  0.00005
```

**實測 per-pixel 雜訊**（T=2500 半段、BIN_FACTOR=2 的 4 px，模擬量測而非假設）：
RMS = **0.041**，且尾端 τ 特別糟：τ=1 是 1.1%，τ=128 是 **42%**。

→ 高於雜訊的奇異方向只有 **4 個**。而且「4 個成分」指的是 4 個平滑奇異方向
（振幅、質心、寬度、一點偏度），**不是 4 群可分辨的族群**。剩下的都是 regulariser 在講話，不是資料。

**順帶一個獨立的問題**：EXP 2 同時測到大 τ 有系統性負偏差（τ=128 低估 **33%**，
finite-T 扣平均造成的）。這偏差正好壓在拉普拉斯反演最依賴的慢速端——
不先修正的話，反演出來的慢成分是假的。這件事跟拉普拉斯無關，對現在的 γ/α fit 也成立。

## 五、兩個 lever：加長 τ 沒用，只有平均有用

**Lever A — 加長 τ 視窗（EXP 6）**：

| τ grid | 4.1% 雜訊 | 0.41% | 0.14% |
|---|---|---|---|
| 1..128 (10 lags, 2.11 dec) | 4 | 6 | 7 |
| 1..512 (12 lags, 2.71 dec) | 4 | 7 | 9 |
| 1..2048 (13 lags, 3.31 dec) | 4 | 8 | 10 |

**在真實的 per-pixel 雜訊下，τ 拉長 16 倍一個成分都沒多。** 綁住的是雜訊，不是 τ 視窗。

**Lever B — 平均 N 個 pixel（EXP 4b）**：能偵測到的最小速率比

| N px | 雜訊 | 可偵測的 R |
|---|---|---|
| 1 | 4.13% | 無 |
| 16 | 1.03% | R ≥ 30 |
| 100 | 0.41% | R ≥ 10 |
| 900 | 0.14% | R ≥ 3 |
| 3600 | 0.07% | R ≥ 2 |

平均是唯一有效的 lever——但平均掉的正是**空間資訊**。也就是說
**沒有 per-pixel 的 α 分離地圖，只有 ROI 級別的答案**。

## 六、跟這個 repo 已有結果的一致性

三件事互相印證：

1. **deliverable 已經用 `global_alpha=True`**（cell 4）——整個核共用一個 α 純量。
   這個工程選擇跟上面的分析一致：per-pixel α 本來就不可辨識。
2. **`fit_gamma_alpha_batched(n_components=2)` 已經存在**（含 Occam penalty）——
   那就是一個 2 點的拉普拉斯反演。它沒被用在 deliverable 裡；EXP 4 說明了為什麼 per-pixel 用不了。
3. **最強的一條**：Section 3 已經把**整條 G(τ) 當 feature 做 full-τ GEVD**，
   用 half-split 驗證，結論是穩健生物軸只有 ~1 條。任何拉普拉斯反演都是**同一組 G(τ) 的確定性函數**，
   由 data processing inequality，它的可複現資訊量**不可能超過**已經量到的上限。
   → 拉普拉斯投影**不會生出新的可複現軸**，最多把那 ~1 條軸換成比較好解釋的單位。

## 七、那什麼做法真的能分開不同的 α？

**要 q 解析度，不是拉普拉斯反演。**

MSD ~ t^α 時，中間散射函數是

```
f(q,t) = exp(−c q² t^α)     →     衰減時間 τ_c(q) ∝ q^(−2/α)
```

**α 是從 τ_c 對 q 的冪次讀出來的**，不是從單一 q 的曲線形狀讀出來的。
兩群即使在某個 q 有相同 τ_c，只要 α 不同，在 q 掃描下就會分開——
這是跟「單一 q 的曲線形狀」正交的一個資訊軸，也正是 per-pixel ACF 缺的那個維度。

實作路徑就是對影像做空間傅立葉 → **DDM / STICS**，得到 `ISF(q, τ)`，
然後每個 q 各自 fit（要反演的話也是每個 q 各自反演，這時 kernel 才是對的）。
STICS 那條線在 `legacy/deep-learning-stics` 分支上有既有程式碼可以接。

這跟 retrospective 的落點一致：要真正的新軸，只能**換採集**或**加正交量測**。

## 八、實務建議

1. **不要做 per-pixel 拉普拉斯地圖。** 出來的每個 pixel 的譜寬只是 α 的重新編碼，
   多峰結構是 regulariser 產生的，不會通過 half-split。
2. **值得跑一次的是 bulk / ROI CONTIN**：

   ```python
   from utils.laplace_spectrum import roi_spectrum
   res = roi_spectrum(CACHE['G'], CACHE['nuc'], RECON_TAUS,
                      G1=CACHE['G1'], G2=CACHE['G2'])
   print(res['n_px'], res['n_peaks'], res['verdict'])
   ```

   整個核 ~10³ px → 能偵測到 R ≳ 3 的雙峰。retrospective 說 bulk 在 (γ, CV²) 空間是單峰，
   但**速率譜空間的 bulk 雙峰還沒測過**，這是個便宜又乾淨的新測試。
   函式會自動用 half-split 算雜訊、跟單成分 fit 比較、檢查峰數在兩半是否重現。
3. **先修 large-τ 的 finite-T 偏差**（第四節）再信任任何慢速端結論。
4. **想要真的分 α → 走 DDM/STICS 的 q 解析路線。**
