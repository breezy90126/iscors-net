# 給 iSCORS 論文作者的分析建議（延伸分析，非更正）
（2026-11-21，依據本 repo 的 iPSF‑kernel CONTIN 分析；詳見 `docs/findings_2026-11-21.md`）

論文以 ACF 擬合得到每 pixel 的單一 D\*，提供了 label‑free 核內動態的空間圖。
我們用同一類資料做了延伸分析，以下三點建議可在不改變實驗的情況下，讓結果更可解讀。

## 1. 除了單一 D\*，報告 D 的分布（兩群的 D 與比例）

- 以 iPSF 為 kernel 的 CONTIN（含白噪聲 nugget、τ=0 錨點、λ 掃描）反演群體層級的 P(D)，
  核內穩定得到**雙峰**：快群 ≈ 4–5 µm²/s、慢群 ≈ 0.26 µm²/s（比值約 20×）。
- 穩健性：三種雜訊篩選（G / G+CV² / τ+CV² GEVD）結果相同；核內被篩掉與保留的 pixel 分布相同；
  三個 λ 下兩峰位置一致；ROI 與 tile 分析一致。
- 單一 D\* 是兩群的加權平均：D\* 改變時，無法區分「分子變慢」與「慢群比例變多」。
- 建議：ROI / 全核層級報 (D_fast, D_slow, 快群比例)，D\* map 保留作為強度加權的摘要。

## 2. 把有限錄影長度與白噪聲放進正向模型

- **有限 T 偏差**：以樣本平均扣除、除以 Ĉ(0) 的估計量，在 T 幀錄影中會壓低慢尾，偏差隨 γ 變大
  （慢 pixel 偏得多）。改用 exact expected estimator 做正向擬合後，全段 T 與半段 T/2 的結果一致。
  → 直接擬合 ACF 的 D\* 在慢區有系統性偏差，且與錄影長度有關，跨實驗比較時需注意。
- **白噪聲**：約佔訊號的 10–18%；未建模時會在 D 上限堆出假的「極快族群」。
- **漂移**：慢群位置會被緩慢漂移拉低；以 matched temporal high‑pass（資料與 kernel 同步處理）檢驗，
  慢群質量保留 0.73×（與無漂移模擬相同）→ 慢群為真，去漂移後位置約 0.26 µm²/s。
- **ACF 形狀指數 α**：擬合 1/(1+γτ^α) 得到的 α ≈ 0.5 是 iPSF 多 q 平均與 pixel 內異質性的有效指數，
  不宜直接當作 MSD 指數或用於聚合物 scaling（如 slope=3）的論述。

## 3. 用藥物擾動區分「分子變慢」與「慢群比例變多」

- 在單一條件下，快群比例在核內幾乎均勻（≈ 0.4；比例圖半段相關 r = 0.19），
  快帶與慢帶強度圖呈同一圖案（核仁暗）。空間上可重現的變化是「擾動強度」，不是動態種類。
  → 空間圖本身難以再推論機制，資訊在於條件間的變化。
- 建議對照：固定細胞（噪聲基準）、ATP 耗竭（主動動態）、TSA（染色質打開）、ActD/DRB（轉錄抑制）、
  1,6‑hexanediol（凝聚體）；每條件多顆細胞，以細胞層級統計比較 (D_fast, D_slow, 比例)。
- 若要指認兩群身分：同細胞 Hoechst / H2B‑GFP 螢光，與快、慢強度圖做相關。

## 限制

- iPSF 目前為 scalar 近似（q_eff ≈ 9.02 rad/µm）：D 的絕對值可能整體差一個倍數（D ∝ 1/q²）；
  比值、比例、空間結構不受影響。需以實測 iPSF 校正。
- 僅分析單一細胞、單一影片（1 s、5 kHz；去漂移後可用約 0.7 s），尚無多細胞統計與擾動實驗。
- 兩群的生物學身分（染色質快/慢模態，或流動池與受束縛池）仍為假說。

## 一句話

不必推翻 D\* map，而是補上 CONTIN 的群體 P(D)：核內有兩群相差約 20 倍、到處等比例混合的動態；
把有限 T 與白噪聲放進模型、並以擾動實驗比較兩群的變化，才能回答 D\* 改變的機制。
